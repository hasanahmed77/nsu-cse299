\begin{abstract}
This report summarizes iterative progress on a full-stack movie streaming project, including implemented modules, resolved technical issues, deployment outcomes, and pending improvements. Work covered frontend development in Next.js, backend API implementation in FastAPI, cloud storage integration through Supabase, and cross-origin deployment debugging. Major effort during this period focused on resolving build-time TypeScript failures, cloud runtime errors, CORS behavior, and database connectivity issues. The current state is functionally deployable with remaining optimization and reliability tasks identified.
\end{abstract}

\section{Detailed Progress by Iteration}
\subsection{Iteration 1: Core Implementation}
\textbf{Completed}
\begin{itemize}
\item FastAPI application structure with route modules \texttt{/auth}, \texttt{/movies}, and \texttt{/history}.
\item SQLAlchemy async integration and model-driven schema responses.
\item Next.js application with pages for home, movie details, search, login/register, and history.
\item Player component using HLS.js fallback for browser compatibility.
\end{itemize}

\textbf{Result}
End-to-end local feature flow became available, but cloud deployment and build consistency required additional work.

\subsection{Iteration 2: Frontend Build Stabilization}
\textbf{Observed Issues}
\begin{itemize}
\item Repeated TypeScript compilation failures on cloud builds.
\item SWR call signatures and data type assumptions produced strict-type errors.
\item Mismatch between expected camelCase fields and backend snake\_case fields.
\end{itemize}

\textbf{Fixes Applied}
\begin{itemize}
\item Added explicit frontend types for API responses.
\item Standardized usage to backend field names (\texttt{hls\_master\_url}, \texttt{duration\_minutes}, \texttt{maturity\_rating}).
\item Updated SWR fetcher typing and conditional rendering guards.
\end{itemize}

\textbf{Result}
Frontend production builds became consistent after type-level cleanup.

\subsection{Iteration 3: Media and Backend Deployment}
\textbf{Observed Issues}
\begin{itemize}
\item GitHub push rejected due to large tracked files (\texttt{node\_modules}, \texttt{.next}, media binaries).
\item Initial backend deployment crashed from incorrect import/entry configuration.
\item Runtime failures when static \texttt{media} folder did not exist in cloud container.
\end{itemize}

\textbf{Fixes Applied}
\begin{itemize}
\item Removed tracked build artifacts from history and excluded generated files.
\item Updated backend entrypoint configuration and import structure.
\item Added conditional static media mount only if folder exists.
\item Migrated video sources to Supabase Storage and used public HLS URLs.
\end{itemize}

\textbf{Result}
Deployment moved from static-local media dependency to cloud storage model.

\subsection{Iteration 4: Connectivity and CORS Hardening}
\textbf{Observed Issues}
\begin{itemize}
\item Intermittent \texttt{500} and \texttt{422} responses from backend.
\item CORS errors from frontend origin despite successful later retries.
\item Cloud DB connection errors involving SSL/network/pooler compatibility.
\end{itemize}

\textbf{Fixes Applied}
\begin{itemize}
\item Reordered ambiguous route declarations to avoid path conflicts.
\item Hardened CORS origin parsing and normalization.
\item Updated DB connection handling for asyncpg and cloud-hosted PostgreSQL constraints.
\item Added environment-driven configuration for API base URL and CORS origins.
\end{itemize}

\textbf{Result}
System reached operational state with remaining reliability tuning focused on request retries and environment consistency.

\section{Risk Register Update}
\begin{itemize}
\item \textbf{Risk:} Recurrent CORS failures during transient backend errors.\\
\textbf{Mitigation:} lock exact allowed origins and verify preflight headers in deployment.
\item \textbf{Risk:} Provider-specific DB SSL behavior.\\
\textbf{Mitigation:} standardize pooler URL and deployment-specific connection args.
\item \textbf{Risk:} Over-fetching from client retries.\\
\textbf{Mitigation:} tune SWR retry and revalidation policy after backend stability confirmation.
\end{itemize}

\section{Conclusion}
Project execution has progressed from prototype implementation to cloud-deployed operation with most core requirements completed. The highest effort was spent on real-world integration problems rather than feature coding, especially deployment configuration, API typing consistency, and cross-origin reliability. The current system is functional and close to final submission quality, with remaining work focused on hardening and predictable operational behavior.
